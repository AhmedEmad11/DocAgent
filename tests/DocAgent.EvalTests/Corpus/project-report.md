# Project Falcon status report

Project Falcon builds the new customer portal. This report describes the state of the project at the end of June.

## Budget

The approved budget for Project Falcon is 250,000 dollars. By the end of June, 180,000 dollars had been spent, which is below the plan for this stage.

## Schedule

The first release is planned for 15 September. The testing phase starts on 1 August and takes six weeks. The portal will be rolled out to customers in two waves.

## Team

The project manager is Laura Chen, who manages the project day to day. The lead engineer is Omar Haddad. The team has nine members, three of whom work part time.

## Risks

The main risk is a delay in the supplier contract for the payment service. The second risk is staff turnover in the testing team.
